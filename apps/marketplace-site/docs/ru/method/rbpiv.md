# RBPIV

Пять стадий (срезы knowledge фильтруются по роль ∩ стадия):

1. **Research** — контекст и ограничения (в основном BA)
2. **Brainstorm** — расхождение вариантов (архитектор / опции Developer)
3. **Plan** — фиксируемый план (design-пакет, план Developer + approve)
4. **Implement** — change-spec и верификация (Developer + arbiter)
5. **Verify** — приёмка по критериям и решениям (BA `accept`, ревью Quality)

Человеческие гейты — на необратимых выборах (vision, council, baselines, записи в Jira). Записи в Jira **опциональны** и не входят в локальный ролевой конвейер.
