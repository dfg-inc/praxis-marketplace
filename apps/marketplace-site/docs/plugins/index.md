# Plugins

Praxis ships role plugins for Claude Code.

| Plugin | Package | License |
|--------|---------|---------|
| praxis-ba | `@praxis/ba` | Apache-2.0 |
| praxis-architect | `@praxis/architect` | Apache-2.0 |
| praxis-developer | `@praxis/developer` | Apache-2.0 |

## Install (Claude Code)

1. Add the marketplace entry or clone the monorepo.
2. Enable the plugin from `.claude-plugin/plugin.json`.
3. Restart the session and verify skills are listed.

Company-only plugins (Jira) are not published under Apache-2.0.
