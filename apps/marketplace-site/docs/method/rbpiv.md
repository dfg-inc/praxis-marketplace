# RBPIV

Five-stage cycle:

1. **Research** — gather context and constraints  
2. **Brainstorm** — diverge on options  
3. **Plan** — lock an executable plan  
4. **Implement** — build with verification  
5. **Verify** — accept against criteria / decisions  

Human gates sit on irreversible choices (vision, architecture council, baselines, Jira writes).
