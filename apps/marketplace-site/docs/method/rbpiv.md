# RBPIV

Five-stage cycle used across roles (knowledge slices are filtered by role ∩ stage):

1. **Research** — gather context and constraints (BA-heavy)
2. **Brainstorm** — diverge on options (Architect alternatives / Developer design options)
3. **Plan** — lock an executable plan (Architect design package, Developer plan + approve)
4. **Implement** — apply change-spec with verification (Developer + arbiter)
5. **Verify** — accept against criteria and decisions (BA `accept`, Quality review)

Human gates sit on irreversible choices (vision, architecture council, baselines, Jira writes). Jira writes are **optional** and not part of the local role pipeline.
